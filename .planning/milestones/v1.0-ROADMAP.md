# Roadmap

## Phase 1: Setup do Projeto e Estrutura Inicial
**Goal:** Inicializar o repositório frontend e construir o layout responsivo base com navegação.
**Mode:** mvp
**Status:** Complete
**Success Criteria:**
1. Projeto compila e roda localmente sem erros.
2. A navegação entre as páginas principais (Sobre, Projetos, Contato) funciona perfeitamente.
**Requirements:** CORE-01

## Phase 2: Tema e Acessibilidade
**Goal:** Implementar funcionalidade de modo light/dark.
**Mode:** mvp
**Status:** Complete
**Success Criteria:**
1. Usuário pode alternar temas via botão na navbar.
2. Cores base mudam adequadamente sem quebrar a leitura.
**Requirements:** CORE-02

## Phase 3: Seção "Sobre"
**Goal:** Criar a seção de perfil focada no recrutador.
**Mode:** mvp
**Status:** Complete
**Success Criteria:**
1. Texto de apresentação visível e bem formatado.
2. Links para redes sociais funcionais e botão de download do currículo ativo.
**Requirements:** CORE-03

## Phase 4: Vitrine (Listagem e Filtros)
**Goal:** Criar o layout em grade para os projetos e o sistema de filtros.
**Mode:** mvp
**Status:** Complete
**Success Criteria:**
1. Projetos mockados são exibidos em grid responsivo.
2. Ao clicar nos botões de filtro, a lista é atualizada.
**Requirements:** PROJ-01

## Phase 5: Componentes de Cards (Bots, APIs, LPs)
**Goal:** Desenvolver as variações de cards para cada categoria de projeto.
**Mode:** mvp
**Status:** Complete
**Success Criteria:**
1. O card de Bot renderiza as tags técnicas.
2. O card de API possui link de documentação claramente visível.
3. O card de Landing Page carrega a imagem de cover corretamente.
**Requirements:** PROJ-02, PROJ-03, PROJ-04

## Phase 6: Polimento e Animações
**Goal:** Adicionar o dinamismo requisitado via micro-interações e transições.
**Mode:** mvp
**Status:** Complete
**Success Criteria:**
1. Mudanças de página possuem transição suave (fade/slide).
2. Hover state dos cards provê feedback visual moderno.
**Requirements:** UI-01, UI-02
