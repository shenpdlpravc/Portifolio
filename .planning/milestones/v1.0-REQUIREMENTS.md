# Requirements

## v1 Requirements

### Estrutura e Navegação
- [ ] **CORE-01**: Layout responsivo com navegação principal (Sobre, Projetos, Contato).
- [ ] **CORE-02**: Suporte interativo a modo dark/light.
- [ ] **CORE-03**: Seção "Sobre" com breve apresentação, links proeminentes para Github, LinkedIn e download de Currículo.

### Vitrine de Projetos
- [ ] **PROJ-01**: Componente de listagem geral exibindo projetos, com filtros por categoria (Bots, APIs, Landing Pages).
- [ ] **PROJ-02**: Card específico de Bot contendo título, resumo funcional, tech stack e link para demonstração.
- [ ] **PROJ-03**: Card específico de API contendo visão geral dos principais endpoints e link para documentação técnica.
- [ ] **PROJ-04**: Card específico de Landing Page contendo imagem de preview de alta qualidade e link live.

### Interatividade e Dinamismo
- [ ] **UI-01**: Transições suaves ao navegar entre seções/páginas.
- [ ] **UI-02**: Micro-interações avançadas (hover states em cards e links) que validam habilidades modernas de frontend.

## v2 Requirements
- **V2-01**: Integração com API do GitHub para exibir número de estrelas/commits dos repositórios listados.
- **V2-02**: Chatbot de apresentação integrado diretamente no portfólio (Demonstração viva).

## Out of Scope
- [Integração de pagamentos ou orçamentos] — O foco atual é a atração de recrutadores, e não captação automática de clientes freelance.
- [Implementação dos Bots e APIs] — O escopo deste projeto é estritamente o site frontend; os bots e APIs estarão em outros repositórios.
