# Plan 01: Configurar ThemeProvider e Theme Toggle

## Objetivo
Implementar o modo light/dark de forma acessível e persistente utilizando `next-themes`.

## Contexto
A Fase 2 do ROADMAP prevê a funcionalidade de troca de tema. Isso exige que Next.js consiga hidratar corretamente a escolha de tema do usuário e que o Tailwind aplique as classes `dark` correspondentes (já configuradas no globals.css na Fase 1).

## Passos de Implementação

1. **Instalar dependências**
   - Instalar `next-themes` via `npm install next-themes` (em bypass mode).

2. **Criar `src/components/theme-provider.tsx`**
   - Criar componente cliente (`"use client"`) que exporta o `ThemeProvider` do `next-themes`.
   - Repassar as props corretamente para que possa envolver toda a aplicação.

3. **Atualizar `src/app/layout.tsx`**
   - Envolver o `children`, `Navbar` e `Footer` com o `ThemeProvider`.
   - Passar `attribute="class"` e `defaultTheme="system"` para ler a preferência do SO por padrão.

4. **Criar `src/components/theme-toggle.tsx`**
   - Criar componente de botão (usando shadcn Button se necessário ou botões nativos).
   - Usar `useTheme` do `next-themes` para alternar entre "light" e "dark".
   - Exibir ícones `Sun` e `Moon` (do `lucide-react`) baseados no tema ativo, com transição CSS suave.

5. **Atualizar `src/components/navbar.tsx`**
   - Inserir o `ThemeToggle` no canto superior direito, próximo aos links sociais e botão de currículo.

## Verification
- O botão na Navbar altera o tema da página e o estado reflete visualmente.
- Nenhuma hidratação incorreta ocorre (flicker de cores ao carregar a página).
- Variáveis CSS `--background` e `--foreground` são aplicadas de acordo com a classe `.dark`.
