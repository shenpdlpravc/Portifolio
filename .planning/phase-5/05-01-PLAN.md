# Plan 01: Componentes de Cards Diferenciados

## Objetivo
Enriquecer a interface visual dos cards de projetos para refletir características específicas de cada tipo de projeto, tornando o portfólio mais atrativo para recrutadores.

## Contexto
Atualmente, todos os projetos compartilham o mesmo layout base de card (título, descrição e tags). Conforme definido no Roadmap (Fase 5), precisamos introduzir detalhes específicos:
- **Bots:** Destacar as tags técnicas (já implementado, mas vamos reforçar a iconografia).
- **APIs:** Incluir links de documentação claramente visíveis.
- **Landing Pages (LPs):** Exibir uma imagem de capa (`coverImage`).

## Passos de Implementação

1. **Atualizar `src/data/projects.ts`**
   - Modificar a interface `Project` para incluir campos opcionais: `docLink?: string`, `githubLink?: string`, e `coverImage?: string`.
   - Atualizar a lista de mock `projects` adicionando esses campos:
     - Adicionar `docLink: "#"` no projeto "Gateway Middleware API" e "Centralized Auth Service".
     - Adicionar `coverImage: "https://images.unsplash.com/photo-1551288049-bebda4e38f71?q=80&w=1000&auto=format&fit=crop"` no projeto "SaaS Analytics LP".
     - Adicionar `githubLink: "#"` em todos os projetos de Bots (e nos demais, como benefício adicional).

2. **Atualizar `src/components/projects-section.tsx`**
   - Importar ícones da `lucide-react` para complementar os links (ex: `ExternalLink`, `Github`, `Book`, `Bot`, `AppWindow`).
   - Refatorar a renderização do `.map` de `filteredProjects`:
     - Se `project.coverImage` existir, renderizar um bloco de imagem (usando a tag `<img>` nativa do HTML com `object-cover h-48 w-full`) no topo do card.
     - Se `project.docLink` existir, renderizar um botão secundário / ghost com ícone de livro ou link externo ("Ver Documentação") logo abaixo das tags.
     - Se `project.githubLink` existir, renderizar um botão icon ghost de Github.
   - Para os Bots, garantir que o estilo das tags seja bem demarcado (usando o componente `<Badge variant="secondary">` que já existe, mas talvez incluir um ícone de `<Bot>` ao lado do título para reforçar a categoria).

## Verification
- Ao selecionar a aba "Landing Pages", o card resultante exibe uma imagem no topo.
- Ao selecionar a aba "APIs", os cards apresentam o botão/link de Documentação.
- Ao selecionar a aba "Bots", os cards exibem o link de Github e/ou as tags formatadas.
