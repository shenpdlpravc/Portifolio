# Plan 02: Padronizar Cor das Tags

## Objective
Corrigir a inconsistência visual apontada pelo usuário onde as APIs parecem ter tags de cores diferentes (devido ao destaque aplicado apenas aos bots).

## Context
Durante a execução do Plano 1, adicionamos um estilo dinâmico onde apenas os projetos do tipo "bot" receberam `variant="default"` (cor primária) nas suas tags, enquanto as outras categorias (APIs e LPs) mantiveram `variant="secondary"`. Isso causou uma percepção de inconsistência visual. Para consertar, vamos padronizar todas as tags para que usem a mesma variante (secondary).

## Implementation Steps
1. Em `src/components/projects-section.tsx`, na iteração `project.tags.map`, alterar:
   De: `variant={project.category === "bot" ? "default" : "secondary"}`
   Para: `variant="secondary"`
   
Isso garantirá que todos os projetos, não importando a categoria, exibam as tags de tecnologia na mesma cor elegante, mantendo a consistência do design.

## Verification
- Ao clicar nas abas "Bots", "APIs", "Landing Pages" e "Todos", as tags de tecnologia (`<Badge>`) deverão estar sempre da mesma cor (secondary) em todos os cards.
