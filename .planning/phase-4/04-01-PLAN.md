# Plan 01: Componentizar Seção de Projetos com Filtros

## Objetivo
Implementar a estrutura principal da vitrine de projetos, criando um sistema de filtros e um grid responsivo que exibe os projetos mockados.

## Contexto
A Fase 4 introduz a listagem de projetos ("Bots", "APIs" e "Landing Pages"). Precisamos ter dados mockados para poder testar os filtros em tempo real, além de uma interface amigável para alternar entre as categorias de projetos. Detalhamento avançado de cada card específico será feito na Fase 5.

## Passos de Implementação

1. **Criar Mocks de Dados (`src/data/projects.ts`)**
   - Exportar uma constante `projects` (array de objetos).
   - O objeto de projeto deve conter: `id`, `title`, `description`, `category` (tipo "bot", "api" ou "landing-page") e um `tags` array opcional.
   - Inserir pelo menos um projeto de cada categoria.

2. **Criar `src/components/projects-section.tsx`**
   - Criar componente Client (`"use client"`) para lidar com o estado do filtro.
   - Declarar o estado `filter` (iniciando como `"all"`).
   - Importar o mock de `projects`.
   - Implementar os botões de filtro: "Todos", "Bots", "APIs", "Landing Pages". O botão ativo deve ter uma variação de cor diferenciada.
   - Criar uma grade (CSS Grid) responsiva: 1 coluna no mobile, 2 no tablet e 3 no desktop (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).
   - Mapear os projetos filtrados na grade, exibindo um card temporário/simples usando `div` ou componentes do Shadcn (Card) se presentes.

3. **Atualizar `src/app/page.tsx`**
   - Remover a seção inline `<section id="projetos">` que era um placeholder.
   - Importar e renderizar o componente `<ProjectsSection />` abaixo do `<AboutSection />`.

## Verification
- A seção de projetos exibe inicialmente todos os projetos mockados.
- Ao clicar em "Bots", apenas projetos com categoria "bot" são mostrados, de forma reativa.
- A grade não quebra a tela e redimensiona corretamente.
