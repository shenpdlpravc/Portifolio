# Plan 01: Criar Seção "Sobre" Profissional

## Objetivo
Componentizar e enriquecer visualmente a seção "Sobre" na página inicial, com foco em impressionar recrutadores com um design moderno, dinâmico e tipografia clara.

## Contexto
Atualmente a seção "Sobre" é apenas um bloco de texto básico no `page.tsx`. O objetivo é criar um componente dedicado (`about-section.tsx`) que agregue foto/avatar, apresentação marcante, badges de habilidades (stack) e links de chamadas de ação (Ver Projetos, Currículo).

## Passos de Implementação

1. **Instalar Componentes Secundários do Shadcn**
   - Executar a instalação dos componentes Badge e Avatar (se disponíveis, ou criá-los nativamente com Tailwind).
   - `npm install lucide-react` (se precisar de mais ícones).

2. **Criar `src/components/about-section.tsx`**
   - Criar um layout responsivo (`flex-col md:flex-row`).
   - Lado esquerdo (ou topo no mobile): Um Avatar estilizado com anel de cor primária.
   - Lado direito (ou corpo): 
     - Título principal "Construindo o futuro com código".
     - Texto descritivo focado no recrutador: "Sou um desenvolvedor especializado em automação, criação de bots inteligentes e APIs escaláveis. Busco resolver problemas complexos com soluções simples e criativas."
   - Criar uma lista de Badges (ex: Node.js, Next.js, React, APIs, Bots).
   - Reintegrar os botões de "Ver Projetos" e "Baixar Currículo".

3. **Atualizar `src/app/page.tsx`**
   - Substituir o código raw da `<section id="sobre">` pela chamada ao novo componente `<AboutSection />`.

4. **Polimento de CSS / Micro-interações**
   - Adicionar transições nos botões (hover).
   - Efeito de fade/subida suave no container (usando classes tailwind como `hover:translate-y-1` nos badges ou `animate-in`).

## Verification
- Ao acessar a página, a seção "Sobre" está bem diagramada, com foto (placeholder visual) e badges.
- O layout quebra corretamente no mobile (empilhado) e fica lado a lado ou centralizado no desktop.
- Todos os links (projetos, contato) redirecionam corretamente.
