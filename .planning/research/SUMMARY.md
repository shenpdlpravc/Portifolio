# Project Research Summary

## Key Findings

**Stack:**
Recomenda-se o uso de React/Next.js ou Vite, aliados ao Tailwind CSS para estilização rápida e Framer Motion para animações que trazem o dinamismo esperado. Hospedagem via Vercel é ideal.

**Table Stakes:**
O essencial inclui uma navegação clara, links fáceis para currículo, GitHub e contatos, além de um design responsivo.

**Watch Out For:**
Evitar overengineering com ferramentas pesadas; manter a performance alta. Importante prever o cenário em que as APIs reais exibidas no portfólio possam estar offline (criando mocks/vídeos de fallback).

## Implications for Roadmap
O foco inicial deve ser na estrutura base (Layout e roteamento) e componentes estáticos modulares que receberão os bots e APIs futuramente. O dinamismo visual (animações) deve ser construído após a base de conteúdo estar finalizada.
