# Features Research

## Table Stakes (Obrigatório)
- Seção "Sobre" com link para currículo e contatos.
- Listagem de Projetos (Bots, APIs, Landing Pages).
- Design responsivo.
- Links diretos para GitHub e deploy.

## Differentiators (Diferenciais)
- Interface de teste/demo inline para os Bots (ex: um chat embutido no site).
- Documentação simplificada inline para as APIs (ex: mini-Swagger).
- Modo escuro/claro interativo.
- Animações fluidas na navegação.

## Anti-features
- Blog complexo (tira o foco).
- E-commerce ou venda de serviços direta.
