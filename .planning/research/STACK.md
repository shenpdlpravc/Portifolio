# Stack Research

## Recommendation
- **Framework**: Next.js (App Router) ou Vite + React
- **Styling**: Tailwind CSS + Framer Motion (para interatividade)
- **Deployment**: Vercel
- **Content/Data**: Arquivos locais (Markdown/JSON) ou Supabase para backend dos futuros bots/APIs.

## Rationale
Para um portfólio de recrutamento focado em bots e APIs, React/Next.js é padrão de mercado e Framer Motion adiciona o "dinamismo" desejado sem complicar a base. Vercel facilita o deploy contínuo.
